# Lighthouse Keepers

Engineering workspace for the Roblox game Lighthouse Keepers. It holds the scripts exported from Studio and the audit and batch documentation.

- `src/`: the game's scripts, exported with Rojo from the Studio place, with the latest batch applied.
- `docs/`: project rules, audits (`docs/audits/TASK-*`) and development batches (`docs/batches/`).
- `tests/`: test material that is preserved but not active, such as the deferred R5 two-server test.

Place files, model files, backups and credentials are deliberately not stored here.
